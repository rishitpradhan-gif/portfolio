# Media credits

## Original portfolio assets

The website design, SVG DNA and fish drawings, interactive experiment interfaces, and procedural Morphogenesis output were created for this portfolio. The DreamIT illustration is AI-generated concept artwork and is labeled as such on the site.

## Drip prototype recording

`public/videos/drip-dashboard.webm` is a silent recording of the existing public prototype at https://drip-demo-dashboard.vercel.app/. It shows time-range changes, chart exploration, and a heatmap with illustrative sample data. It does not connect to a visitor's wearable.

`public/images/drip-demo-dashboard.webp` is a screenshot of that prototype and serves as the video's poster fallback.
